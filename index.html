A 欧拉角：三次绕轴旋转的记录

三个数就是三张「转多少度」的便签，按约定的顺序贴： 先绕 X（俯仰 pitch）转 α， 再绕 Y（偏航 yaw）转 β， 最后绕 Z（滚转 roll）转 γ。 它记的是过程而不是姿态本身——所以顺序换了结果就换（02 节）， 某些角度还会三根轴卡成两根（05 节）。

B 旋转矩阵：三根轴的新家

把旋转之后三根轴各自指向哪、坐标是什么，全部写下来：矩阵的 第一列是原 X 轴的新坐标、第二列是原 Y 轴的、 第三列是原 Z 轴的。九个数看着多，但三列必须互相垂直、长度为 1， 所以真正的自由度还是 3 个。它没法直观想象，但「向量乘一下就转完」最快——图形管线的最终形态就是它。

C 四元数：轴角减半打包

一个转弯其实只需要两样：绕哪根轴 n̂、转多远 θ。 四元数把它们打包进 4 个数：q = [cos(θ/2), sin(θ/2)·n̂]—— 实部 w 管角度，虚部 (x, y, z) 管轴的方向。 注意角度被减半：这正是它躲开万向锁、还能顺滑插值的秘密（03 节细讲）。 把它作用到向量上用「三明治」：v′ = q v q⁻¹。

三种语言说的是同一件事，各有一摊数学可以互相换算——你在上面的演示里看到的三个面板永远同步，就是这个原因。 真正拉开差距的是用起来：接下来四节，各看一个坑或一个本事。

02

先学会「转」：三个虚轴，乘法不对易

Hamilton 的 i、j、k 是三个「平方等于 −1」的方向量。对旋转来说， 它们最关键的性质是：相乘的顺序不能换—— ij = k，而 ji = −k。 下面的两串动作，用的都是「绕 X 90°」和「绕 Y 90°」这两步，只是顺序不同。

q = I

试一试：两条路径各跑一遍。两步都绕固定的世界轴（场景里细长的三根）转， 飞机上亮的彩色轴只是被带着走——第二步看起来像在绕蓝 Z 转，只是因为第一步转完后飞机的 Z 箭头恰好倒在了世界 Y 上； 发光的轴线与环形箭头会标出每一步真正绕转的轴。最后对比飞机自己的绿 Y 箭头： 一条路指向 +X，另一条指向 +Z。 旋转不对易；四元数的乘法 j⊗i = −k 忠实地记住了这一点——这不是缺陷，是它「懂」旋转的证据。

03

一半的角度：q 与 −q 是同一个旋转

绕单位轴 n̂ 转 θ，对应四元数 q = [cos(θ/2), sin(θ/2)·n̂]——注意角度被减半。 作用到向量上用「三明治」：v′ = q v q⁻¹。 减半带来一个奇妙结论：转满 360° 时 q 变成 −q， 而 −q 和 q 表示同一个旋转；要转满 720°，四元数才回到起点。

0°

两架小飞机，左边由 q 驱动，右边由 −q 驱动——盯住它们，永远一致。 标尺上 360° 处标着 −q₀： 那一刻实部 w 变了号，但姿态一模一样。 这个「双倍覆盖」不是数学游戏——神经网络输出 q 时差一个正负号完全无所谓（06 节会再用到它）。

这是欧拉角的死穴，也是四元数登场的经典理由。三只陀螺环各管一个角： 偏航 yaw、俯仰 pitch、 滚转 roll。把 pitch 拉到 ±90°， 外环和内环就共线了——三个自由度瞬间只剩两个。

06

AlphaFold 里的四元数

蛋白质是一条氨基酸链，AlphaFold2 的结构模块给每个残基都配了一个局部坐标系 （frame）：原点钉在 Cα 上，轴向顺着 N、C 等主链原子。整条蛋白质的形状， 就是一串 frame 的「位置 + 旋转」。

旋转那一半，存的正是单位四元数：比 3×3 矩阵省 5 个数； 合法性约束只有一句「归一化」；网络每轮预测要微调每个 frame 时， 做的是一次四元数乘法再归一化——小幅修正永远是小幅旋转，光滑、可导、不跳变。

你在 03 节看到的「q ≡ −q」在这里也是真实的工程细节： 网络吐出的四元数差一个正负号，旋转意义完全相同。而评估结构用的 FAPE 损失， 本质就是在这些 frame 之间做对齐、量误差——底层的几何词汇还是四元数与旋转矩阵。

q ← normalize( q ⊗ Δq )

每按一次，链条上每个 frame 都朝各自的新目标平滑滑过去—— 连按几次，就是一轮轮预测迭代。没有跳变、没有锁死，这正是四元数被选中的原因。

07

AlphaFold 到底输出什么：一张残基身份证

先认识骨架：主链、肽键、能转的单键

蛋白质是一条氨基酸链。撑起形状的骨架（backbone）是每个残基重复的三个原子： N（氮）、Cα（α 碳，侧链挂在它身上）、 C（羰基碳，身上还挂着一个红色的 O）。 一个残基的 C 与下一个残基的 N 之间由肽键相连——整条链就是 [N–Cα–C]ₙ 的重复。

骨架上真正能转的只有两根单键：N–Cα（转动角叫 φ）和 Cα–C（转动角叫 ψ）。 肽键 C–N 有双键性质，把周围的原子锁死在同一个平面里（肽平面）， 它的扭转角 ω 几乎恒为 180°。所以主链每个残基只有两个真正的自由角 φ、ψ—— 这就是为什么拉马钱德兰图只有横纵两个轴。侧链挂 Cα 逐节扭转，叫 χ₁ ∼ χ₄，侧链越长用到的越多。

这些角都是四个原子的二面角：按 A–B–C–D 排四个原子，绕中间的 B–C 键转动， A 端和 D 端的夹角就是扭转角——你在下面的折叠机里拖任意一个滑块，高亮的就是它对应的四个原子和旋转轴。

每个残基的「身份证」：t、q 与 7 个扭转角

结构模块对每个残基吐出一张「身份证」，两部分。第一部分是骨架变换： 平移 t = (x, y, z)，3 个数，说「这个残基的坐标系原点（Cα）钉在空间的哪儿」； 四元数 q，4 个数，说「坐标系朝哪儿」——就是 06 节的主角。 合起来 3 + 4 = 7 个数，定死一个局部坐标系。

第二部分是 7 个扭转角：主链的 ω、φ、ψ（ω 是肽键两侧， 几乎恒为 180°；φ、ψ 是主链真正能扭的两处——拉马钱德兰图的横纵轴）， 加侧链的 χ₁ ∼ χ₄（侧链上的可旋转单键，侧链越长用得越多）。 每个角不直接输出度数，而是输出一个二维向量，归一化到单位长度后当作 (cos, sin) 用——一共 7 × 2 = 14 个数。

骨架折叠机：拖 ψ、φ，主链绕单键转动；拖 ω 到 0° 可以看到罕见的顺式肽键（顺式会让侧链撞在一起，真实蛋白里极少）。 按住任意滑块时，它对应的四个原子与旋转轴会高亮、其余变暗，右上角同步说明它是哪串原子的二面角。 按「α 螺旋 / β 折叠」一键摆到拉马钱德兰图的著名区域。 下方 t 是残基 2 的 Cα 位置（3 个数），右侧四条读数是它的朝向 q（4 个数）——原子坐标就是用它们加扭转角「长」出来的。

那为什么扭转角要绕个弯、输出 (cos, sin) 而不是直接回归角度？ 因为角度有悬崖：−180° 和 +180° 是同一个方向， 数值上却差着 360——网络在这条缝上学得死去活来。改成单位向量，方向连续、处处光滑； 网络要是「拿不准」，就把向量输出得短一些，归一化后照样投影回圆上。 损失函数也简单：就是两支单位向量之间的距离。

把灰点拖过 ±180° 那条红缝——角度数字会跳变，琥珀色箭头却连续地转过去。 这就是 AlphaFold 用向量编码角度的全部理由：让网络要学的东西处处光滑。
