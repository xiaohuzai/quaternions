01

主链是什么：N、Cα、C 与肽键

撑起蛋白质形状的骨架（backbone）是每个残基重复的三个原子： N（氮）、Cα（α 碳，侧链挂在它身上）、 C（羰基碳，身上还挂着一个红色的 O）。 一个残基的 C 与下一个残基的 N 之间由肽键相连——整条链就是 [N–Cα–C]ₙ 的重复。

骨架上真正能转的只有两根单键：N–Cα 和 Cα–C。 肽键 C–N 有双键性质，把周围的原子锁死在同一个平面里（肽平面）， 它的扭转角几乎恒为 180°。侧链挂在 Cα 上，沿单键逐节扭转——这些「转多少度」， 就是接下来要认识的各种角。

首屏那条链可以拖着看：蓝 = N、骨白 = Cα、琥珀 = C、红 = O、绿 = 侧链。 记住这个配色，后面全用它。

02

二面角：四个原子，绕中间的键转

蛋白质里所有的「角」都是同一类东西——二面角。 按 A–B–C–D 排四个原子，中间的 B–C 是旋转轴： 绕它转动时，A 端和 D 端的夹角就是二面角。 拖下面的滑块亲手转一转。

灰色 = 两端原子 A、D；琥珀键 B–C 是旋转轴，环形箭头标出转动方向。 真实蛋白里 B–C 就是骨架或侧链上的那根单键。

三个特殊的二面角给它们起了名字——φ、ψ、ω（在主链上）和 χ（在侧链上）。 名字不同，几何完全是同一回事：四个原子、一根中间键、一个角度。

04

χ：侧链的角

侧链挂在 Cα 上，是一串碳（以及氮、氧、硫）接出来的「尾巴」。尾巴上的每一根单键都能转， 转动角依次叫 χ₁、χ₂、χ₃、χ₄——还是二面角那一套， 只是四个原子换成了侧链上的原子（比如 χ₁ = N–Cα–Cβ–Cγ）。 侧链越长，用到的 χ 越多：

0 个 χ（没有侧链碳）

侧链的 χ 不是随便乱转的：绕单键转动时，相邻基团错开（交错构象）能量最低， 所以 χ 偏好扎堆在 ±60° 和 180° 附近—— 这些稳定组合叫 rotamer（旋转异构体），结构生物学里查表用的就是它。 上一节的折叠机切到 K·4 拖 χ 滑块，就能看到侧链一节一节展开。

05

残基的「身份证」：t、q 与 7×2 个数

AlphaFold2 的结构模块对每个残基输出两部分。第一部分是骨架变换： 平移 t = (x, y, z)，3 个数，说「这个残基的坐标系原点（Cα）钉在空间的哪儿」； 朝向 q，4 个数，说「坐标系朝哪儿」——用的是四元数（附录有速成）。 合起来 3 + 4 = 7 个数，定死一个局部坐标系。

第二部分是 7 个扭转角：主链的 ω、φ、ψ 加侧链的 χ₁ ∼ χ₄——就是这一页前三节讲的那些角。 每个角不直接输出度数，而是输出一个二维向量，归一化到单位长度后当作 (cos, sin) 用——一共 7 × 2 = 14 个数。

为什么绕这个弯？因为角度有悬崖：−180° 和 +180° 是同一个方向， 数值上却差着 360——网络在这条缝上学得死去活来。改成单位向量，方向连续、处处光滑； 网络要是「拿不准」，就把向量输出得短一些，归一化后照样投影回圆上。

把灰点拖过 ±180° 那条红缝——角度数字会跳变，琥珀色箭头却连续地转过去。 损失函数就是两支单位向量之间的距离（绿虚线）。这就是 AlphaFold 用向量编码每个角的全部理由。

06

从角到三维结构

原子坐标并不是凭空输出的。给定每个残基的 (t, q) 与全部扭转角， 用标准键长、键角（N–Cα 1.46Å、Cα–C 1.53Å、C–N 1.33Å……）把原子一个个「长」出来—— 03 节的折叠机干的就是这件事（它用的算法叫 NeRF，神经网络侧也常用同一套几何）。

AlphaFold 每轮预测会微调每个残基的 q（四元数乘法 + 归一化， 保证永远是光滑的小旋转）和各个扭转角，一轮一轮逼近真实结构。 下面的演示模拟这个过程：按一次，就是一轮「预测更新」。
