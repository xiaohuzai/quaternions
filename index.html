01

残基的输出清单：分成两类

先把账单摊开。每个氨基酸的输出不多不少，就两类：

一、骨架变换 backbone transform

7 个数

平移 t = (x, y, z)，3 个数—— 残基的坐标系原点（Cα）钉在空间的哪儿；
四元数 q，4 个数——骨架的朝向。 合起来定死一个局部坐标系（frame）。

二、7 个扭转角 torsion angles

7 × 2 = 14 个数

骨架上的 ω、φ、 ψ，加侧链的 χ₁ ∼ χ₄（侧链越长，用到的 χ 越多）。 每个角输出一个二维向量，归一化到单位长度后当作 (cos, sin) 用。

接下来的路线：02 讲第一类（t 与 q，含 q 是什么、为什么用它）； 03–05 讲第二类（扭转角是什么、骨架的三个、侧链的四个）； 06 讲为什么每个角是 2 个数；07 把 21 个数拼回三维结构。 首屏那条链可以拖着看：蓝 = N、骨白 = Cα、琥珀 = C、红 = O、绿 = 侧链——记住配色，后面全用它。

02

第一类：骨架变换——平移 t 与朝向 q

每个残基带一个局部坐标系（frame）：原点钉在 Cα 上，三根轴顺着主链的方向—— 约定是 x 轴指向 C、y 轴朝 N 一侧。 描述这个坐标系只需要两样东西——平移 t = (x, y, z)， 3 个数，说「原点在哪儿」；四元数 q，4 个数，说「朝向哪儿」。 7 个数，定死一个残基的骨架摆放。

t 和 q 是相对谁说的？都是相对全局坐标系—— 整个结构共用的那个「世界系」，也就是最终原子坐标（PDB 文件）所在的坐标系。 t = Cα 在全局系里的位置；q = 残基系相对全局系的朝向。 每个残基都直接对全局系说话，不是相对上一个残基存的。

下面的演示里，每套坐标架就是一个残基的坐标系（蓝球 = N、骨白球 = Cα、琥珀球 = C， 三色箭头 = 残基系的轴）：t 定它的位置，q 定它的朝向。 AlphaFold 每轮预测会微调每个 q（四元数乘法 + 归一化，永远是光滑的小旋转）和 t，一轮轮逼近真实结构。

q 与 −q 是同一个旋转

四元数打包的是「绕哪根轴 n̂、转多远 θ」： q = [cos(θ/2), sin(θ/2)·n̂]——角度被减半。 于是转满 360° 时 q 变成 −q，而两者是同一个旋转； 720° 才回到本尊。网络输出 q 差一个正负号完全无所谓——这在训练里是真实的工程细节。

03

第二类的统一定义：扭转角就是二面角

7 个扭转角是同一类东西——二面角。 按 A–B–C–D 排四个原子，中间的 B–C 是旋转轴： 绕它转动时，A 端和 D 端的夹角就是二面角。 拖下面的滑块亲手转一转——φ、ψ、ω、χ 只是给七串特定的四个原子起了名字。

60°

灰色 = 两端原子 A、D；琥珀键 B–C 是旋转轴，环形箭头标出转动方向。 真实蛋白里 B–C 就是骨架或侧链上的那根单键。

04 节的三个角在骨架上，05 节的四个角在侧链上——几何完全相同。

05

侧链的四个角：χ₁ ∼ χ₄

侧链挂在 Cα 上，是一串碳（以及氮、氧、硫）接出来的「尾巴」。尾巴上的每一根单键都能转， 转动角依次叫 χ₁、χ₂、χ₃、χ₄——还是二面角那一套（比如 χ₁ = N–Cα–Cβ–Cγ）。 侧链越长，用到的 χ 越多，最多 4 个：

甘氨酸 Gly

0 个 χ（没有侧链碳）

丝氨酸 Ser / 半胱氨酸

1 个 χ

天冬氨酸 Asp / 亮氨酸

2 个 χ

谷氨酸 Glu / 甲硫氨酸

3 个 χ

赖氨酸 Lys / 精氨酸

4 个 χ

取值偏好

±60°、180°（交错构象 rotamer）

侧链的 χ 不是随便乱转的：绕单键转动时，相邻基团错开（交错构象）能量最低， 所以 χ 偏好扎堆在 ±60° 和 180° 附近—— 这些稳定组合叫 rotamer（旋转异构体），结构生物学里查表用的就是它。 04 节的折叠机切到 K·4 拖 χ 滑块，就能看到侧链一节一节展开。

06

每个角为什么是 2 个数：(cos, sin) 编码

7 个扭转角，每个不直接输出度数，而是输出一个二维向量， 归一化到单位长度后当作 (cos, sin) 用——一共 7 × 2 = 14 个数。

为什么绕这个弯？因为角度有悬崖：−180° 和 +180° 是同一个方向， 数值上却差着 360——网络在这条缝上学得死去活来。改成单位向量，方向连续、处处光滑； 网络要是「拿不准」，就把向量输出得短一些，归一化后照样投影回圆上。 损失函数也简单：就是两支单位向量之间的距离。

把灰点拖过 ±180° 那条红缝——角度数字会跳变，琥珀色箭头却连续地转过去。 每个扭转角都这样编码一次，7 × 2 = 14 个数，这就是第二类输出的全部形状。

07

把 21 个数拼回三维结构

两类输出合起来就是答案。给定每个残基的 (t, q)（骨架变换）与全部 (cos, sin)（扭转角），用标准键长、键角 （N–Cα 1.46Å、Cα–C 1.53Å、C–N 1.33Å……）把原子一个个「长」出来—— 04 节的折叠机干的就是这件事（算法叫 NeRF，神经网络侧也常用同一套几何）。

(t, q) 定每个残基「钉在哪儿、朝哪儿」， 扭转角定「角与角之间怎么弯」——一条原子级精确的三维结构就此成型。
